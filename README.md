# Guia 156 Osasco

Consulta rápida para o atendimento do 156 de Osasco: orientações, documentos para agendamento, endereços e telefones dos serviços públicos.

- Abre direto no navegador, sem login.
- Inclusões e correções da equipe ficam salvas no banco (Supabase) e exigem o PIN da equipe.
- Favoritos podem ser levados para outros computadores com um código pessoal.
